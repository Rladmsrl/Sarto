## What changed

- **Fixed:** Sarto no longer quits when you open Settings, most often on the Cloud Sync & Multi-Device and Advanced & Service pages.

### Bug Fixes

- **Settings crash on open**: v0.3.3 loaded each Settings page's data with Swift `async let`, which the release build's compiler (Swift 6.1, [swiftlang/swift#81771](https://github.com/swiftlang/swift/issues/81771)) can miscompile into an abort ("freed pointer was not the last allocation"). The pages still load their data in parallel, and switching pages or hosts still cancels the previous page's requests.

## 中文

- **修复**：修复打开设置时 Sarto 闪退的问题，「云同步与多设备互联」和「高级与服务」两页最容易触发。

### Bug 修复

- **打开设置闪退**：v0.3.3 的设置页用 Swift 的 `async let` 加载数据，发布版所用的编译器（Swift 6.1，[swiftlang/swift#81771](https://github.com/swiftlang/swift/issues/81771)）可能把它编译错，导致程序中止（"freed pointer was not the last allocation"）。现在各页仍并行加载数据，切换页面或主机时，上一页的请求仍会一并取消。
