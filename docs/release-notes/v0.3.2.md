## What changed

- Reworked Dynamic Island around cross-Mac approvals, clearer reset times, and better display and energy handling.
- Added native Markdown HTML preview with palette-aware styling and faster file search and tree watching.
- Simplified Settings with per-Mac island and menu bar toggles, automatic displays, and unified low-quota alerts.
- Fixed Gatekeeper verification on bundled Node, inline approval of proposed memories, and Antigravity usage reading.
- Locked the in-development idle game off by default so nothing loads or connects until it launches.

- 新增原生 Markdown HTML 预览（适配主题配色），并优化文件检索速度与受保护目录的监听策略。
