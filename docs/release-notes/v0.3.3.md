## What changed

- **New:** Official headless Linux daemon (`linux-x64` & `linux-arm64`, glibc 2.28+) with `install.sh` and systemd user service.
- **New:** Pause mobile APNs pushes while this Mac is active and alerts reach you, catching up once you step away.
- **New:** Streamlined macOS Settings with remote-host scope clarity, full search, dynamic fonts, and worktree copy paths.
- **Fixed:** Keep Remote Claude hosted runs alive across idle stops and updates, and recover cleanly when hosts close.
- **Fixed:** Hardened Settings state sync, multi-Mac device management, presence retries, and Linux daemon update verification.

### New Features

- **Headless Linux daemon & multi-platform releases**: Ship standalone `sarto-daemon-linux-x64.tar.gz` and `sarto-daemon-linux-arm64.tar.gz` built against glibc 2.28, add `--channel stable|beta` and preflight libc checks to `install.sh`, and harden `systemd --user` bus discovery and linger handling.
- **Desktop presence-aware mobile push**: Track Mac lock, sleep, console session, recent input, and alert reachability via `DesktopPresenceMonitor`, pausing `onlyAway` mobile notifications while you are actively at your Mac.
- **Streamlined macOS Settings**: Reorganize tabs into clearer Client, Host, Advanced & Service, and Updates & About sections; add a remote-host scope banner with quick switch-back to This Mac; index all settings rows for search; load full system font families and model choices; and add worktree copy-paths configuration.

### Bug Fixes

- **Remote Claude stability**: Prevent idle stops and background updates from terminating agents with live hosted runs, watch agent connection closures cleanly, and mark reclaimed runs reliably on `not_found` or `unavailable` errors.
- **Settings accuracy & performance**: Fix remote-host `defaultAgent` and verbose-logging state sync, restore multi-Mac synced device management, remove dead controls and orphan localization keys, cache font/search/plugin computations, throttle accent color writes, and parallelize section RPCs.
- **Presence & daemon hardening**: Retry desktop presence sync across reconnects with graceful fallback for older daemons, guard musl/glibc detection in `install.sh`, enforce per-platform SHA-256 pinning during `sarto update`, and verify `GLIBC`/`GLIBCXX` ABI ceilings across native addons.

## 中文

- **新功能**：正式支持无头 Linux Daemon（`linux-x64` 与 `linux-arm64`，glibc 2.28+），提供一键安装脚本与 systemd 服务托管。
- **新功能**：新增「在电脑前时暂停手机推送」，当 Mac 活跃且灵动岛或系统通知可达时暂缓移动端推送，离开后自动补发。
- **新功能**：全面精简重构 macOS 设置窗口，支持远程主机作用域提示、全项检索、动态系统字体与 Worktree 复制路径配置。
- **修复**：修复 Remote Claude 托管会话在空闲回收、后台更新及连接关闭时的中断与恢复异常。
- **修复**：修复设置页远程状态同步、多 Mac 设备管理与性能卡顿，并加固在场检测重试与 Linux 更新验签。

### 新功能

- **无头 Linux Daemon 与多平台发布**：同步发布基于 glibc 2.28 基线构建的 `linux-x64` / `linux-arm64` 独立安装包；安装脚本支持 `--channel stable|beta`、前置 musl/glibc 校验与 `systemd --user` 自动配置。
- **电脑活跃时智能暂停手机推送**：通过 `DesktopPresenceMonitor` 实时感知锁屏、休眠、控制台会话、近期键鼠输入以及灵动岛/系统通知可达状态，在电脑前时避免手机重复打扰，离开后自动补发待处理通知。
- **重构 macOS 设置页布局**：精简并重组设置分组（拆分为「高级与服务」与「更新与关于」并移除冗余归档页），新增远程主机作用域横幅与一键切回本机，为全部设置项建立搜索索引，补齐系统字体列表与 Worktree 复制路径配置。

### Bug 修复

- **Remote Claude 稳定性修复**：将托管会话计入活跃会话计数以防误触发空闲停止或自动更新中断，监听底层连接关闭并妥善处理 `not_found` / `unavailable` 重连与配置状态恢复。
- **设置页状态同步与性能优化**：修复远程主机默认 Agent 与详细日志状态、恢复多 Mac 同步设备管理、清理无效开关与冗余本地化词条，并缓存字体/搜索/插件计算、节流主题色板写入、并行化设置区 RPC。
- **在场检测与 Linux Daemon 安全加固**：为桌面在场同步增加断线重试与旧版兼容，加固 `install.sh` 的 musl/glibc 检测、无头 systemd 总线环境变量补齐、多平台 SHA-256 精确锁定以及原生扩展 ABI 门禁校验。
